Orion Wallet — คู่มือผู้ใช้

Orion Wallet ทำงานทั้งหมดภายในเบราว์เซอร์ของคุณ คีย์ของคุณถูกสร้างขึ้นในเครื่อง และเข้ารหัส
ด้วย PIN ของคุณ โดยจัดเก็บไว้บนอุปกรณ์ของคุณเท่านั้น ไม่มีการส่งข้อมูลใดไปยังเซิร์ฟเวอร์

GitHub: github.com/maragung/OrionWallet — โค้ดต้นฉบับ ประเด็นปัญหา และเวอร์ชันเผยแพร่

สารบัญ

  • เริ่มต้นใช้งาน
  • การสร้างกระเป๋าเงิน
  • การนำเข้ากระเป๋าเงินที่มีอยู่
  • การใช้งานในชีวิตประจำวัน
  • ผู้ติดต่อ (สมุดที่อยู่)
  • บัญชีแบบเฝ้าดู
  • ยอดคงเหลือแบบเข้ารหัส (FHE)
  • การโอนแบบ stealth
  • การเชื่อมต่อกับ dApp
  • การล็อกและปลดล็อก
  • การหมดอายุของเซสชัน
  • การตั้งค่าเครือข่าย
  • การสำรองข้อมูลและการกู้คืน
  • การแก้ไขปัญหา
  • การดูแลเงินทุนของคุณให้ปลอดภัย

เริ่มต้นใช้งาน

ข้อกำหนด

  • เบราว์เซอร์ Chrome, Edge, Firefox หรือ Safari เวอร์ชันปัจจุบัน
  • เปิดใช้งาน JavaScript แล้ว
  • RAM ประมาณ 4 GB หากคุณวางแผนจะใช้ฟีเจอร์ยอดคงเหลือแบบเข้ารหัส

การเรียกใช้งาน

ใช้บริการที่โฮสต์ไว้ให้ หรือเรียกใช้ในเครื่องของคุณ:

npm install --legacy-peer-deps
npm run dev

จากนั้นเปิด <http://localhost:5173>

การสร้างกระเป๋าเงิน

  1. เลือก Create New Wallet ตั้งชื่อบัญชี และเลือก PIN PIN จะใช้เข้ารหัสกระเป๋าเงินบนอุปกรณ์นี้
  2. จดวลีกู้คืนของคุณไว้ คุณจะเห็นคำ 12 คำ จงคัดลอกลงบนกระดาษตามลำดับที่ให้ไว้ทุกประการ
  3. เลือก I've Written It Down จากนั้นกระเป๋าเงินจะให้คุณพิมพ์ 3 คำ ที่สุ่มเลือกขึ้นมาใหม่ เพื่อพิสูจน์ว่าวลีนั้นออกจากหน้าจอไปแล้วจริง ๆ หากต้องการดูอีกครั้ง Show Phrase Again
    จะนำกลับมาแสดง คำตอบที่ผิดก็เพียงให้คุณลองใหม่เท่านั้น
  4. เมื่อคำต่าง ๆ ผ่านการตรวจสอบแล้ว กระเป๋าเงินก็จะเปิดขึ้น
การสร้างกระเป๋าเงินไม่ได้หมายความว่ามันจะเปิดขึ้น — การผ่านการตรวจสอบคำต่างหาก ก่อนหน้านั้นคุณ
ยังเดินออกไปได้เสมอ และไม่มีอะไรสูญหาย เพราะยังไม่ได้พึ่งพาวลีดังกล่าว
วลีกู้คืนของคุณคือหนทางเดียวในการกู้คืนกระเป๋าเงินของคุณ ผู้ที่ครอบครองมัน
จะควบคุมเงินทุนของคุณได้ จงเก็บไว้แบบออฟไลน์ ห้ามถ่ายภาพ ห้ามพิมพ์ลงในเว็บไซต์
หรือวางลงในแชทหรืออีเมล

PIN เทียบกับวลีกู้คืน

วลีกู้คืนPIN
วัตถุประสงค์กู้คืนกระเป๋าเงินของคุณได้ทุกที่ปลดล็อกบนอุปกรณ์นี้เท่านั้น
หากสูญหายเงินทุนไม่สามารถกู้คืนได้กู้คืนจากวลีกู้คืน
เก็บไว้ที่ใดออฟไลน์ โดยตัวคุณเองไม่มีการจัดเก็บ — มีเพียงคุณเท่านั้นที่รู้

การนำเข้ากระเป๋าเงินที่มีอยู่

เลือก Import และเลือกวิธีใดวิธีหนึ่งจากนี้:

  • วลีกู้คืน — ป้อนคำ 12/24 คำของคุณ
  • คีย์ส่วนตัว — วางคีย์ส่วนตัวแบบ base64
  • ไฟล์กระเป๋าเงิน — อัปโหลดไฟล์ .oct ที่เข้ารหัสแล้วป้อน PIN ของมัน

การใช้งานในชีวิตประจำวัน

การตรวจสอบยอดคงเหลือ

แท็บ Balance แสดงยอดคงเหลือสาธารณะของคุณ และหากเปิดใช้ PVAC ก็จะแสดงยอดคงเหลือที่เข้ารหัสด้วย

การรับเงิน

เปิด Receive เพื่อแสดงที่อยู่และคิวอาร์โค้ดของคุณ ที่อยู่ของคุณเป็นข้อมูลสาธารณะและ
ปลอดภัยที่จะแชร์

คุณยังสามารถขอจำนวนเงินที่ระบุได้ คิวอาร์โค้ดจะบรรจุจำนวนเงินควบคู่ไปกับที่อยู่
(ในรูปแบบ octra:<address>?amount=<OCT>) ดังนั้นกระเป๋าเงินที่สแกนมันจะเติมทั้งสองค่าให้อัตโนมัติ
หากไม่ได้ขอจำนวนเงิน โค้ดก็จะคงเป็นที่อยู่เปล่า ๆ ซึ่งสแกนเนอร์ใดก็อ่านได้

การส่งเงิน

  1. เปิด Send
  2. ระบุผู้รับในแบบที่สะดวกสำหรับคุณ:
    • วางที่อยู่ (ขึ้นต้นด้วย oct)
    • เลือกชื่อที่บันทึกไว้จาก 📇 Contacts…
    • เลือก 📷 Scan เพื่ออ่านคิวอาร์โค้ดด้วยกล้องของคุณ เบราว์เซอร์จะขอสิทธิ์กล้องในครั้งแรก รูปภาพจะถูกประมวลผลภายในหน้าเว็บและไม่มีการอัปโหลด การสแกนโค้ดที่บรรจุจำนวนเงินจะกรอกจำนวนเงินให้ด้วย
  3. ป้อนจำนวนเงิน
  4. ตรวจสอบค่าธรรมเนียมและ nonce แล้วยืนยันด้วย PIN ของคุณ

เมื่อที่อยู่ตรงกับผู้ติดต่อที่บันทึกไว้ ฟอร์มจะแสดงชื่อข้าง ๆ ที่อยู่นั้น — ชื่อที่คุณ
จำได้คือเครื่องมือตรวจสอบที่ดีกว่าสตริง base58 มาก สำหรับที่อยู่ใหม่ ＋ Save to
contacts จะบันทึกมันภายใต้ป้ายชื่อที่คุณเลือก เพื่อให้การชำระครั้งต่อไปเป็นการเลือก ไม่ใช่การวาง

ควรตรวจสอบอักขระตัวแรกและตัวสุดท้ายของที่อยู่ผู้รับเสมอก่อนยืนยัน

ประวัติ

History แสดงรายการธุรกรรมล่าสุด เมื่อเครือข่ายไม่สามารถเข้าถึงได้ รายการที่แคชไว้
จะถูกแสดงและทำเครื่องหมาย ⚠ Cached

⤓ ส่งออกตารางเป็นไฟล์ CSV (เวลา, แฮช, ประเภท, จาก, ถึง, ทิศทาง, จำนวน, ค่าธรรมเนียม,
สถานะ) สำหรับสเปรดชีตหรือบันทึกส่วนตัวของคุณ โดยมันส่งออกเฉพาะแถวที่โหลดอยู่ในขณะนั้น —
เห็นอะไรก็ได้อย่างนั้น — ดังนั้นควรใช้ Load more ก่อนหากคุณต้องการช่วงที่ยาวขึ้น
ไฟล์ถูกเขียนโดยเบราว์เซอร์ของคุณไปยังโฟลเดอร์ดาวน์โหลด ไม่มีการส่งอะไรไปที่ใด

ผู้ติดต่อ (สมุดที่อยู่)

Settings → 📇 Contacts เก็บรายการที่อยู่ภายใต้ชื่อที่คุณเลือก รายการแต่ละรายการมี
ที่อยู่ ชื่อ และหมายเหตุเพิ่มเติม — จุดที่ดีสำหรับ "ต้องระบุ memo" หรือว่าที่อยู่สำหรับฝาก
ของแต่ละเอ็กซ์เชนจ์นั้นเป็นของใคร

ทำไมจึงควรใช้: ที่อยู่ที่คุณอ่านไม่ออกคือที่อยู่ที่คุณตรวจสอบไม่ได้ เมื่อผู้รับถูกบันทึกแล้ว
ฟอร์ม Send จะเสนอพวกเขาด้วยชื่อ และติดป้ายชื่อที่อยู่เมื่อคุณวางมันกลับมา ดังนั้น
ที่อยู่ที่ถูกสับเปลี่ยนหรือถูกตัดทอนจะเด่นชัดขึ้นแทนที่จะกลมกลืนไป

  • Add รายการได้ที่นี่ หรือใช้ ＋ Save to contacts จากฟอร์ม Send ได้โดยตรง
  • ✎ เปลี่ยนชื่อรายการ 🗑 ลบรายการ การลบผู้ติดต่อไม่กระทบสิ่งใดบนเชน
  • ⤓ ส่งออกรายการเป็น CSV เพื่อเก็บไว้กับบันทึกอื่นของคุณหรือย้ายไปยังเบราว์เซอร์อื่น

ผู้ติดต่อจะอยู่ในเบราว์เซอร์นี้เท่านั้น ควบคู่ไปกับข้อมูลกระเป๋าเงินที่เหลือของคุณ พวกมัน
ไม่ถูกอัปโหลด และจะถูกลบทิ้งพร้อมกับทุกสิ่งหากคุณล้างกระเป๋าเงิน

บัญชีแบบเฝ้าดู

บัญชีแบบเฝ้าดูจะติดตามที่อยู่ที่คุณไม่ได้ถือคีย์ — คลังเย็น กระเป๋าเงินฮาร์ดแวร์
ที่อยู่สำหรับฝากของเอ็กซ์เชนจ์ หรือที่อยู่ของคนอื่นที่คุณจับตาดูอยู่

เพิ่มได้ภายใต้ Settings → 👥 Accounts → 👁 Watch Address: วางที่อยู่ ตั้งชื่อให้มัน
แล้วมันจะเข้าร่วมรายการบัญชีของคุณ

สิ่งที่มันทำได้: แสดงยอดคงเหลือ แสดงรายการประวัติ ส่งออก CSV และสลับมาใช้ได้โดยไม่ต้องใช้
PIN — ไม่มีที่เก็บคีย์ให้ถอดรหัส จึงไม่มีอะไรให้ปลดล็อก

สิ่งที่มันทำไม่ได้: เซ็นอะไรก็ไม่ได้ การส่ง การเข้ารหัส/ถอดรหัส การโอนแบบ stealth การเรียก
สัญญา และคำขอเซ็นจาก dApp ถูกปฏิเสธทั้งหมด และฟอร์ม Send จะบอกก่อนที่คุณจะกรอกข้อมูล
เสียอีก ไม่ใช่บอกทีหลัง บัญชีแบบเฝ้าดูจะถูกทำเครื่องหมาย 👁 ในรายการบัญชีและใน
แถบส่วนหัว เพื่อให้คุณรู้เสมอว่ากำลังดูแบบไหนอยู่

หากต้องการเปลี่ยนบัญชีแบบเฝ้าดูให้เป็นบัญชีจริง ให้นำเข้าวลีกู้คืนหรือคีย์ส่วนตัวของ
ที่อยู่นั้น การเพิ่มคีย์เป็นหนทางเดียวเท่านั้น ไม่มีทางลัด

ยอดคงเหลือแบบเข้ารหัส (FHE)

Orion Wallet สามารถเก็บยอดคงเหลือส่วนหนึ่งของคุณในรูปแบบที่เข้ารหัสด้วยการเข้ารหัสแบบ fully homomorphic
เพื่อให้จำนวนเงินไม่ปรากฏต่อสาธารณะบนเชน

ฟีเจอร์นี้เป็นตัวเลือก ทุกอย่างอื่นทำงานได้ไม่ว่าจะเปิดใช้หรือไม่ก็ตาม

การเปิดใช้

ไปที่ Settings → PVAC ตัวบ่งชี้สองตัวต้องเป็นสีเขียวทั้งคู่:

  • WASM Module — โมดูลการเข้ารหัสโหลดแล้ว
  • Bridge Initialized — มันถูกสร้างคีย์จากซีดของกระเป๋าเงินคุณแล้ว

หากตัวใดตัวหนึ่งยังไม่พร้อม แผงจะอธิบายสาเหตุที่แท้จริงและวิธีแก้ไข

การเข้ารหัสและถอดรหัส

ใช้ Encrypt เพื่อย้ายเงินระหว่างยอดคงเหลือสาธารณะและยอดคงเหลือที่เข้ารหัสของคุณ การดำเนินการเหล่านี้
ใช้ทรัพยากรการคำนวณสูงและอาจใช้เวลาหลายวินาที ไดอะล็อกความคืบหน้าจะแสดงแต่ละขั้นตอน

การโอนแบบ stealth

การโอนแบบ stealth ส่งเงินไปยังที่อยู่แบบใช้ครั้งเดียวที่ได้มาจากคีย์สาธารณะของผู้รับ
เพื่อให้การชำระเงินไม่สามารถเชื่อมโยงกับที่อยู่หลักของพวกเขาได้ต่อสาธารณะ

เปิด Stealth ป้อนผู้รับและจำนวนเงิน แล้วยืนยัน ผู้รับจะรับเงินจากแท็บ Stealth ของตนเอง

การเชื่อมต่อกับ dApp

เมื่อเว็บไซต์ขอเชื่อมต่อ ป็อปอัปจะปรากฏขึ้นแสดงต้นทาง (origin) ที่ร้องขอ

ก่อนอนุมัติ:

  • ตรวจสอบ origin อย่างรอบคอบ ยืนยันว่าโดเมนคือเว็บไซต์ที่คุณตั้งใจไว้จริง ๆ
  • อนุมัติเฉพาะสิทธิ์ที่คุณคาดหวังเท่านั้น
  • "Trust this site" ข้ามพรอมป์ในอนาคตสำหรับคำขอแบบอ่านอย่างเดียว — ใช้มันเท่าที่จำเป็น
  • ตรวจสอบตัวเลือกเครือข่ายในป็อปอัป มันแสดงรายการทุกเครือข่ายที่คุณมี รวมถึง
    เครือข่ายที่คุณเพิ่มเอง ดังนั้นคุณจึงเชื่อมต่อบนเครือข่ายที่ถูกต้องได้โดยไม่ต้องออกจากป็อปอัป

ตรวจสอบและเพิกถอนการเชื่อมต่อได้ทุกเมื่อภายใต้ Settings → Connected Sites

การล็อกและปลดล็อก

PIN ของคุณใช้ถอดรหัสกระเป๋าเงิน คีย์ที่ถอดรหัสแล้วจะพร้อมใช้งานตลอดระยะเวลาที่
เซสชันการปลดล็อกดำเนินอยู่ — คุณจะไม่ถูกถามหา PIN อีกจนกว่าเซสชันจะสิ้นสุด

  • การรีเฟรชหน้าทำให้คุณยังปลดล็อกอยู่ คีย์จะถูกผนึกใหม่สำหรับแท็บเบราว์เซอร์
    ที่คุณอยู่ ดังนั้นการรีโหลดจะกลับมารับเซสชันต่อแทนที่จะส่งคุณกลับไปที่หน้าจอ PIN
    คุณจะเห็นข้อความ "Restoring your session…" ในช่วงสั้น ๆ ขณะที่มันเกิดขึ้น
  • การปิดแท็บจะสิ้นสุดเซสชัน สำเนาที่ผนึกไว้จำกัดอยู่แค่แท็บนั้นแท็บเดียวและ
    หายไปพร้อมกับมัน ดังนั้นแท็บหรือหน้าต่างใหม่จะเริ่มต้นด้วยสถานะล็อก
  • 🔒 ในแถบส่วนหัวล็อกทันที และทำลายสำเนาที่ผนึกไว้ — การรีโหลดหลัง
    การล็อกจะถามหา PIN ตามที่ควรจะเป็น
  • การไม่ใช้งานจะล็อกกระเป๋าเงิน หลังจาก 30 นาทีโดยค่าเริ่มต้น และการปลดล็อกหนึ่งครั้ง
    จะไม่ถูกยืดเกิน 8 ชั่วโมงไม่ว่าจะมีการใช้งานหรือไม่ก็ตาม

ทั้งสองครึ่งของเซสชันที่ผนึกไว้ไม่มีประโยชน์เมื่ออยู่ตามลำพัง: คีย์ที่เข้ารหัสถูกถือโดย
แท็บ ขณะที่คีย์ที่ใช้เปิดมันถูกเก็บโดยเบราว์เซอร์ในรูปแบบที่ไม่มีหน้าเว็บใด —
รวมถึงหน้านี้ — อ่านกลับออกมาได้

ภายใต้ Settings → Security → Session & Auto-Lock:

การตั้งค่าค่าเริ่มต้นมันทำอะไร
Stay unlocked after a page refreshเปิดปิดเพื่อให้ต้องใส่ PIN ทุกครั้งที่รีโหลด
Auto-lock after inactivity30 นาที5 / 15 / 30 / 60 นาที หรือไม่เลย (จนกว่าแท็บจะปิด)

ทั้งสองข้อมีผลพร้อมกัน รวมถึงกับเซสชันที่คุณเปิดอยู่แล้ว บนคอมพิวเตอร์ที่ใช้ร่วมกันหรือ
ไม่น่าไว้วางใจ ให้ปิดข้อแรกและล็อกกระเป๋าเงินเมื่อคุณเดินออกไป

การปลดล็อกด้วย passkey

หากอุปกรณ์ของคุณมีเครื่องอ่านลายนิ้วมือ, Face ID, Windows Hello หรือคีย์ความปลอดภัย คุณก็สามารถ
ปลดล็อกด้วยสิ่งเหล่านั้นแทนการพิมพ์ PIN ได้

เปิดใช้ภายใต้ Settings → 🔑 Security → Passkey Unlock → Enable passkey unlock อุปกรณ์ของคุณ
จะแจ้งให้คุณลงทะเบียน — อาจแจ้งสองครั้ง ครั้งหนึ่งเพื่อสร้าง passkey และอีกครั้งเพื่อใช้มัน
หน้าจอปลดล็อกจะเสนอ 👆 Unlock with passkey เหนือกล่อง PIN

เรื่องน่ารู้:

  • PIN ยังคงมีอยู่และยังคงสำคัญ passkey ใช้เปิดกระเป๋าเงิน มันไม่ได้แทนที่ PIN การส่งออกคีย์ การเปิดเผยวลีกู้คืน การเปลี่ยน PIN และการสร้างบัญชีใหม่ยังคงต้องใช้ PIN ทั้งหมด จงเก็บ PIN ไว้ — การทำหายมันไม่สามารถแก้ไขได้ด้วยการมี passkey
  • มันผูกติดกับอุปกรณ์และเบราว์เซอร์นี้ passkey ไม่เดินทางไปกับข้อมูลกระเป๋าเงินของคุณ บนอุปกรณ์อื่น ให้ปลดล็อกด้วย PIN และลงทะเบียน passkey ที่นั่นหากต้องการ
  • ลายนิ้วมือของคุณไม่มีทางไปถึงกระเป๋าเงิน อุปกรณ์ยืนยันตัวตนคุณในเครื่องและส่ง
    ความลับที่ได้มาจาก passkey ให้หน้าเว็บ ความลับนั้นคือสิ่งที่ใช้เปิดกระเป๋าเงิน
  • ความพร้อมใช้งานขึ้นอยู่กับอุปกรณ์และเบราว์เซอร์ของคุณ หากอุปกรณ์ของคุณไม่สามารถทำตามที่จำเป็นได้
    แผง Security จะบอก และตัวเลือกจะยังคงปิดอยู่ — PIN ยังคงทำงานเหมือนเดิมทุกประการ
  • ปิดการปลดล็อกด้วย passkey ได้ในแผงเดียวกัน การทำเช่นนั้นจะลบสำเนาที่เก็บไว้ทันที
    มันไม่ได้ลบ passkey จากอุปกรณ์ของคุณ ซึ่งคุณสามารถลบได้ในการตั้งค่าระบบปฏิบัติการหรือ
    เบราว์เซอร์

หาก passkey ใดหยุดเปิดกระเป๋าเงิน — ข้อมูลประจำตัวที่ถูกหมุนหรือลงทะเบียนใหม่ หรือ
อุปกรณ์ที่ถูกกู้คืน — กระเป๋าเงินจะบอกคุณ ทิ้งสำเนาที่เก่าค้าง และถามหา PIN
ไม่มีอะไรสูญหาย คุณสามารถลงทะเบียน passkey ใหม่ได้ในภายหลัง

ไม่สามารถลงทะเบียนการปลดล็อกด้วย passkey ได้ในขณะที่บัญชีแบบเฝ้าดูกำลังทำงานอยู่ — มันไม่มีคีย์
จึงไม่มีอะไรให้ passkey ผนึก แผง Security จะบอกแทนปุ่ม

การหมดอายุของเซสชัน

กรอบเวลาเดียวกันนี้ควบคุมการเชื่อมต่อ dApp ซึ่งหมดอายุโดยอัตโนมัติ:

  • การหมดเวลาเมื่อไม่ใช้งาน: ไม่มีการใช้งาน 30 นาที
  • การหมดเวลาแบบสัมบูรณ์: 8 ชั่วโมงนับจากเชื่อมต่อ

เมื่อเซสชันหมดอายุ กระเป๋าเงินจะปิดการเชื่อมต่อและ dApp จะได้รับการแจ้งเตือน
จากนั้น dApp ควรแจ้งให้คุณเชื่อมต่อใหม่

เกิดอะไรขึ้นเมื่อเซสชันของคุณหมดอายุ

  1. กระเป๋าเงินส่งอีเวนต์ sessionExpired ไปยัง dApp
  2. dApp ตรวจพบเซสชันที่หมดอายุและแสดงพรอมป์ "Reconnect"
  3. คุณคลิก Connect เพื่อเปิดป็อปอัปกระเป๋าเงินอีกครั้ง
  4. กระเป๋าเงินกู้คืนเซสชันของคุณและ dApp กลับมาทำงานต่อ

หาก dApp ไม่เชื่อมต่อใหม่อัตโนมัติ

  • คลิกปุ่ม Connect ใน dApp
  • ป็อปอัปกระเป๋าเงินเปิดขึ้น — อนุมัติการเชื่อมต่อ
  • ข้อมูลเซสชันก่อนหน้าของคุณยังคงอยู่ ดังนั้นคุณไม่ต้องนำเข้ากระเป๋าเงินอีกครั้ง

การตั้งค่าเครือข่าย

Settings → ⚙️ General เก็บ URL RPC ที่กระเป๋าเงินใช้สื่อสาร, explorer ที่มันเชื่อมโยงออกไป
และพร็อกซีเสริม เปลี่ยน URL RPC แล้วเลือก Save URLs เพื่อชี้กระเป๋าเงินไปยังโหนดอื่น

การเพิ่มเครือข่ายของคุณเอง

Devnet และ Mainnet มาพร้อมกับกระเป๋าเงิน หากต้องการเพิ่มเครือข่ายอื่น — โหนดของคุณเอง, devnet fork,
RPC แบบเสียเงิน — เลื่อนไปที่ Custom Networks ในแผงเดียวกันแล้วกรอก:

ฟิลด์จำเป็นหมายเหตุ
Network nameใช่แสดงทุกที่ที่เครือข่ายปรากฏ รวมถึงต่อ dApp
RPC URLใช่http:// หรือ https://
Explorer URLไม่ค่าเริ่มต้นคือ RPC URL
Relayer URLไม่จำเป็นสำหรับการโอนแบบ stealth เท่านั้น

เลือก Add network แล้วมันจะเข้าร่วมรายการ จากนั้นมันก็เป็นตัวเลือกปกติ:

  • network pill ในแถบด้านบนจะสลับไปหามันเหมือนกับเครือข่ายที่ตั้งไว้ล่วงหน้าอื่น ๆ
  • connect popup จะแสดงมันเมื่อเว็บไซต์ขอเชื่อมต่อ โดยทำเครื่องหมาย (custom)
  • และ dApp ที่เชื่อมต่ออยู่สามารถอ่านชื่อและ explorer ของมันเพื่อติดป้ายชื่อสิ่งต่าง ๆ ได้อย่างถูกต้อง

การสลับเครือข่ายจะอัปเดตปลายทางทั้งสามพร้อมกัน — RPC, explorer และ relayer — เพื่อให้กระเป๋าเงิน
ไม่ลงเอยด้วยการอ่านเครือข่ายหนึ่งขณะเชื่อมโยงไปยังอีกเครือข่ายหนึ่ง

ลบเครือข่ายด้วย ✕ ข้าง ๆ มัน หากคุณลบเครือข่ายที่กำลังใช้อยู่ กระเป๋าเงินจะ
กลับไปใช้เครือข่ายที่ตั้งไว้ล่วงหน้า

สิ่งที่ dApp เห็น เว็บไซต์ที่คุณเชื่อมต่อสามารถอ่านชื่อเครือข่ายแบบกำหนดเอง, ไอคอน, URL explorer
และข้อเท็จจริงที่ว่าคุณเพิ่มมันเข้าไป พวกมันไม่สามารถอ่าน URL RPC หรือ relayer ของมัน — ที่อยู่
โหนดบ้านหรือคีย์ของผู้ให้บริการจะยังคงอยู่ในกระเป๋าเงิน เนื่องจากชื่อนั้นมองเห็นได้ จึงควรหลีกเลี่ยง
การตั้งชื่อเครือข่ายตามสิ่งที่เป็นข้อมูลส่วนตัว

โหนดที่ไม่มี HTTPS

โหนด https:// ไม่ต้องการการจัดการพิเศษ โหนดที่เข้าถึงได้ผ่าน http:// ธรรมดาเท่านั้น
เป็นอีกเรื่องหนึ่ง เพราะทุกอย่างที่กระเป๋าเงินถามมัน — การค้นหายอดคงเหลือและประวัติทุกรายการ
ธุรกรรมทุกอันที่มันส่ง — เดินทางแบบไม่เข้ารหัส ซึ่งใครก็ตามบนเส้นทางเครือข่าย
สามารถอ่านมันได้ และเปลี่ยนคำตอบได้ ดังนั้นกระเป๋าเงินจึงถามก่อน

  • Loopback ไม่ต้องขออนุญาต localhost, 127.0.0.1, [::1] และพวกพ้องไม่เคย
    ออกจากเครื่องของคุณ ดังนั้นโหนดในเครื่องจึงทำงานได้ทันที
  • ที่อยู่ http:// อื่นใดต้องได้รับความไว้วางใจอย่างชัดแจ้ง วาง URL แล้วแผงจะอธิบาย
    ว่ามีอะไรเสี่ยง พร้อมปุ่ม Trust http://… ข้าง ๆ ความไว้วางใจถูกจัดเก็บ
    ต่อ origin (scheme, โฮสต์ และพอร์ต) ดังนั้นการไว้วางใจโหนดหนึ่งไม่ได้ไว้วางใจอีกโหนดหนึ่ง และ
    พอร์ตต่างกันบนโฮสต์เดียวกันคือการตัดสินใจที่แยกจากกัน
  • Trusted plaintext endpoints แสดงรายการสิ่งที่คุณไว้วางใจแล้ว พร้อมปุ่ม Remove เพื่อ
    นำกลับคืน

ข้อจำกัดสองข้อไม่ใช่สิ่งที่เราจะยกให้ได้ และแผงจะระบุชื่อว่าข้อใดขวางอยู่:

  • กระเป๋าเงินที่ให้บริการผ่าน https:// ไม่สามารถเรียก http:// ได้เลย เบราว์เซอร์บล็อกสิ่งนั้น
    (เรียกว่า mixed content) และการไว้วางใจ origin จะไม่เปลี่ยนแปลงมัน จงใส่โหนดไว้
    หลัง TLS ใช้พร็อกซี หรือเปิดกระเป๋าเงินจากบิลด์ plain-http หรือ localhost
  • บิลด์ที่เผยแพร่อนุญาตเฉพาะ https:// และ loopback เท่านั้น นโยบายความปลอดภัยของมันถูกกำหนดตายตัว
    ตอนบิลด์ และไม่สามารถขยายได้ในขณะที่รัน ผู้ที่โฮสต์เองซึ่งต้องการ http ธรรมดา
    สามารถบิลด์ด้วย VITE_ALLOW_HTTP_ENDPOINTS=1; รายการความไว้วางใจข้างต้นยังคงมีผลเพิ่มเติม

URL explorer ได้รับการยกเว้นจากทั้งหมดนี้ — มันเป็นเพียงลิงก์ที่คุณคลิกเท่านั้น ไม่ใช่
สิ่งที่กระเป๋าเงินเรียกดึง

พร็อกซี RPC

RPC proxy (optional) ส่งต่อคำขอผ่าน URL ที่คุณเลือก: RPC URL จะถูกต่อท้าย
แบบ percent-encoded และเบราว์เซอร์จะเชื่อมต่อกับพร็อกซีเท่านั้น มันคือ
ทางออกเชิงปฏิบัติสำหรับโหนดที่ไม่มี TLS หรือไม่มีหัว CORS และมันเป็นไปตามกฎข้างต้น
เพราะการเชื่อมต่อที่เบราว์เซอร์ทำคือการเชื่อมต่อไปยังพร็อกซี

พร็อกซีเห็นทุกคำขอที่กระเป๋าเงินทำ ดังนั้นจงรันพร็อกซีของคุณเอง มันไม่สามารถเซ็นอะไร
หรือเข้าถึงคีย์ของคุณได้ แต่มันสามารถเฝ้าดูและสามารถโกหกได้

เมื่อมีสิ่งผิดปกติ

หากไม่สามารถใช้ปลายทาง RPC ตามที่ตั้งค่าไว้ ⚠️ Insecure RPC จะปรากฏในแถบส่วนหัว
เลือกมันเพื่อข้ามไปยังการตั้งค่านั้นทันที ข้อผิดพลาดของเครือข่ายยังพกสาเหตุมาด้วย ดังนั้น
"Failed to fetch" เปล่า ๆ จะบอกคุณว่าต้องแก้ไขอะไร

กระเป๋าเงินไม่สามารถเปิดฐานข้อมูลในเครื่องของมันได้ ไม่มีอะไรถูกลบ — นี่เกือบ
ทุกครั้งเป็นแท็บ Orion อื่น หรือป็อปอัป Connect ที่ค้างอยู่ ยังคงยึดฐานข้อมูลเปิดไว้
หลังการอัปเดต เบราว์เซอร์จะไม่อัปเกรดฐานข้อมูลในขณะที่แท็บเก่ายังผูกติดอยู่กับมัน

ปิดแท็บและป็อปอัป Orion อื่น ๆ แล้วเลือก ↻ Try again หากข้อความยังคงอยู่
ให้ปิดแท็บ Orion ทั้งหมดแล้วเปิดกระเป๋าเงินใหม่ในแท็บเดียว

หน้าจอปลดล็อกแยกสองสถานะนี้ให้ต่างกันโดยเจตนา: No stored wallet found หมายความว่า
ฐานข้อมูลว่างจริง ๆ ขณะที่ Could not read your saved wallets หมายความว่าบัญชีของคุณอยู่ที่นั่น
แต่ไม่สามารถเข้าถึงได้ชั่วคราว อย่าสร้างกระเป๋าเงินใหม่ ในขณะที่คุณเห็น

อย่าสร้างกระเป๋าเงินใหม่ — นั่นอาจเขียนทับข้อมูลเก่า จงรายงาน

dApp บอกว่า "Session expired"

คลิก Connect ใน dApp ข้อมูลกระเป๋าเงินของคุณยังคงอยู่ — คุณเพียงแค่ต้อง

ควรทำ

  • เก็บวลีกู้คืนของคุณแบบออฟไลน์ บนกระดาษ ควรเก็บไว้มากกว่าหนึ่งแห่ง
  • ตรวจสอบที่อยู่ผู้รับก่อนส่ง
  • ตรวจสอบ origin ที่แสดงในพรอมป์การเชื่อมต่อ dApp
  • เริ่มด้วยธุรกรรมทดสอบเล็กน้อยเมื่อส่งไปยังที่อยู่ใหม่
  • บันทึกผู้รับเป็นผู้ติดต่อ และตรวจสอบชื่อ — ชื่อที่คุณจำได้ดีกว่าการอ่าน base58
  • ใช้บัญชีแบบเฝ้าดูเพื่อจับตาคลังเย็น แทนที่จะปลดล็อกบัญชีจริง

ห้ามเด็ดขาด

  • ป้อนวลีกู้คืนของคุณบนเว็บไซต์ใด ๆ Orion Wallet จะไม่มีวันขอหลังจากตั้งค่าแล้ว
  • เก็บวลีในภาพหน้าจอ โน้ตในตัวจัดการรหัสผ่าน ไดรฟ์คลาวด์ หรือแชท
  • แชร์คีย์ส่วนตัวหรือไฟล์ .oct ของคุณ
  • ใช้กระเป๋าเงินที่ถือเงินจริงบนคอมพิวเตอร์ที่ใช้ร่วมกันหรือไม่น่าไว้วางใจ
