Orion Wallet — பயனர் வழிகாட்டி

Orion Wallet முழுவதுமாக உங்கள் உலாவியிலேயே இயங்குகிறது. உங்கள் சாவிகள் உள்ளூரிலேயே உருவாக்கப்பட்டு, உங்கள் PIN மூலம் குறியாக்கம் செய்யப்பட்டு,
உங்கள் சாதனத்தில் மட்டுமே சேமிக்கப்படுகின்றன. எதுவும் ஒரு சேவையகத்திற்கு அனுப்பப்படுவதில்லை.

GitHub: github.com/maragung/OrionWallet — மூலக் குறியீடு, சிக்கல்கள் மற்றும் வெளியீடுகள்.

தேவைகள்

  • Chrome, Edge, Firefox அல்லது Safari-இன் தற்போதைய பதிப்பு
  • JavaScript இயக்கத்தில் இருத்தல்

இயக்குதல்

வழங்கப்பட்ட (hosted) பதிப்பைப் பயன்படுத்தவும், அல்லது அதை உள்ளூரில் இயக்கவும்:

npm install --legacy-peer-deps
npm run dev

பிறகு <http://localhost:5173>-ஐத் திறக்கவும்.

வாலட்டை உருவாக்குதல்

  1. Create New Wallet-ஐத் தேர்ந்தெடுத்து, கணக்கிற்குப் பெயரிட்டு, ஒரு PIN-ஐத் தேர்வுசெய்யவும். PIN இந்தச் சாதனத்தில் வாலட்டைக் குறியாக்குகிறது.
  2. உங்கள் மீட்புச் சொற்றொடரை எழுதி வைக்கவும். உங்களுக்கு 12 சொற்கள் காட்டப்படும். கொடுக்கப்பட்ட சரியான வரிசையில் அவற்றைக் காகிதத்தில் நகலெடுக்கவும்.
  3. I've Written It Down-ஐத் தேர்ந்தெடுக்கவும். சொற்றொடர் உண்மையில் திரையை விட்டு நீங்கியதை நிரூபிக்க, சீரற்ற முறையில் தேர்ந்தெடுக்கப்பட்ட 3 சொற்களை மீண்டும் தட்டச்சு செய்ய வாலட் கேட்கும். மீண்டும் பார்க்க வேண்டுமானால் Show Phrase Again
    அதை மீண்டும் கொண்டுவரும்; தவறான பதில் மீண்டும் முயற்சிக்க மட்டுமே உங்களை அனுமதிக்கிறது.
  4. சொற்கள் சரிபார்க்கப்பட்டதும், வாலட் திறக்கிறது.
வாலட்டை உருவாக்குவது அதைத் திறக்காது — சொல் சரிபார்ப்பில் தேர்ச்சி பெறுவதே திறக்கும். அதுவரை நீங்கள்
இன்னும் வெளியேறலாம், எதுவும் இழக்கப்படாது, ஏனெனில் சொற்றொடர் இன்னும் நம்பப்பட்டிருக்கவில்லை.
உங்கள் மீட்புச் சொற்றொடர்தான் உங்கள் வாலட்டை மீட்டெடுக்கும் ஒரே வழி. அதை வைத்திருப்பவர் யாராக இருந்தாலும்
உங்கள் நிதியைக் கட்டுப்படுத்துவார். அதை ஆஃப்லைனில் சேமிக்கவும். அதை ஒருபோதும் புகைப்படம் எடுக்கவோ, ஒரு இணையதளத்தில் தட்டச்சு செய்யவோ,
அல்லது அரட்டை அல்லது மின்னஞ்சலில் ஒட்டவோ வேண்டாம்.

PIN எதிராக மீட்புச் சொற்றொடர்

மீட்புச் சொற்றொடர்PIN
நோக்கம்எங்கிருந்தும் உங்கள் வாலட்டை மீட்டெடுக்கிறதுஇந்தச் சாதனத்தில் மட்டுமே திறக்கிறது
இழந்தால்நிதியை மீட்க முடியாதுமீட்புச் சொற்றொடரிலிருந்து மீட்டெடுக்கவும்
எங்கே சேமிக்கப்படுகிறதுஆஃப்லைனில், உங்களிடம்ஒருபோதும் சேமிக்கப்படாது — உங்களுக்கு மட்டுமே தெரியும்

ஏற்கனவே உள்ள வாலட்டை இறக்குமதி செய்தல்

Import-ஐத் தேர்ந்தெடுத்து, பின்வருவனவற்றில் ஒன்றைத் தேர்வுசெய்யவும்:

  • Recovery phrase — உங்கள் 12/24 சொற்களை உள்ளிடவும்
  • Private key — ஒரு base64 தனிப்பட்ட சாவியை ஒட்டவும்
  • Wallet file — ஒரு குறியாக்கப்பட்ட .oct கோப்பைப் பதிவேற்றி அதன் PIN-ஐ உள்ளிடவும்

அன்றாட பயன்பாடு

உங்கள் இருப்பைச் சரிபார்த்தல்

Balance தாவல் உங்கள் பொது இருப்பையும், PVAC இயக்கப்பட்டிருந்தால், உங்கள் குறியாக்கப்பட்ட இருப்பையும் காட்டுகிறது.

பெறுதல்

உங்கள் முகவரியையும் ஒரு QR குறியீட்டையும் காட்ட Receive-ஐத் திறக்கவும். உங்கள் முகவரி பொதுவானது, பகிர்வதற்குப்
பாதுகாப்பானது.

நீங்கள் குறிப்பிட்ட தொகையைக் கோரவும் முடியும். அப்போது QR குறியீடு முகவரியுடன் சேர்த்து அந்தத் தொகையையும்
எடுத்துச் செல்கிறது (octra:<address>?amount=<OCT> என), எனவே அதை ஸ்கேன் செய்யும் ஒரு வாலட் இரண்டையும் முன்கூட்டியே நிரப்புகிறது.
தொகை எதுவும் கோரப்படாவிட்டால், குறியீடு வெறும் முகவரியாகவே இருக்கும், அதை எந்த ஸ்கேனரும் படிக்கலாம்.

அனுப்புதல்

  1. Send-ஐத் திறக்கவும்.
  2. பெறுநரை உங்களுக்கு வசதியான வழியில் குறிப்பிடவும்:
    • முகவரியை ஒட்டவும் (அது oct-இல் தொடங்குகிறது).
    • 📇 Contacts…-இலிருந்து சேமித்த பெயரைத் தேர்ந்தெடுக்கவும்.
    • உங்கள் கேமரா மூலம் QR குறியீட்டைப் படிக்க 📷 Scan-ஐத் தேர்ந்தெடுக்கவும். முதல் முறை உலாவி கேமரா அனுமதி கேட்கும்; படம் பக்கத்திலேயே செயலாக்கப்பட்டு ஒருபோதும் பதிவேற்றப்படாது.
      தொகையைச் சுமக்கும் குறியீட்டை ஸ்கேன் செய்தால் அந்தத் தொகையும் நிரப்பப்படும்.
  3. ஒரு தொகையை உள்ளிடவும்.
  4. கட்டணத்தையும் nonce-ஐயும் மதிப்பாய்வு செய்து, பிறகு உங்கள் PIN மூலம் உறுதிப்படுத்தவும்.

முகவரி சேமித்த தொடர்புடன் பொருந்தும்போது, படிவம் அதற்கு அருகில் பெயரைக் காட்டுகிறது — நீங்கள் அடையாளம் காணும் பெயர்,
base58 சரத்தைப் படிப்பதை விட மிகச் சிறந்த சரிபார்ப்பு. புதிய முகவரிக்கு, ＋ Save to
contacts அதை நீங்கள் தேர்வுசெய்யும் லேபிளின் கீழ் சேமிக்கிறது, அடுத்த கட்டணம் ஒட்டுதலாக அல்ல, தேர்வாக இருக்கும்.

உறுதிப்படுத்தும் முன் பெறுநரின் முகவரியின் முதல் மற்றும் கடைசி எழுத்துகளை எப்போதும் சரிபார்க்கவும்.
பரிவர்த்தனைகளை மாற்றியமைக்க முடியாது.

வரலாறு

History சமீபத்திய பரிவர்த்தனைகளைப் பட்டியலிடுகிறது. நெட்வொர்க்கை அடைய முடியாதபோது, கேச் செய்யப்பட்ட உள்ளீடுகள்
காட்டப்பட்டு ⚠ Cached எனக் குறிக்கப்படும்.

⤓ அட்டவணையை CSV கோப்பாக ஏற்றுமதி செய்கிறது (நேரம், hash, வகை, இருந்து, வரை, திசை, தொகை, கட்டணம்,
நிலை) — ஒரு விரிதாள் அல்லது உங்கள் சொந்த பதிவுகளுக்காக. இது தற்போது ஏற்றப்பட்ட வரிசைகளை ஏற்றுமதி செய்கிறது —
நீங்கள் பார்ப்பதே நீங்கள் பெறுவது — எனவே நீண்ட வரம்பு வேண்டுமானால் முதலில் Load more-ஐப் பயன்படுத்தவும்.
கோப்பு உங்கள் உலாவியால் உங்கள் downloads கோப்புறையில் எழுதப்படுகிறது; எதுவும் எங்கும் அனுப்பப்படுவதில்லை.

தொடர்புகள் (முகவரிப் புத்தகம்)

Settings → 📇 Contacts நீங்கள் தேர்வுசெய்யும் பெயர்களின் கீழ் முகவரிகளின் பட்டியலை வைத்துள்ளது. ஒவ்வொரு உள்ளீட்டிலும்
ஒரு முகவரி, ஒரு பெயர் மற்றும் ஒரு விருப்பக் குறிப்பு இருக்கும் — "memo required" போன்றவற்றுக்கோ, ஒரு வைப்பு முகவரி எந்த
எக்ஸ்சேஞ்சிற்குச் சொந்தமானது என்பதற்கோ இது நல்ல இடம்.

ஏன் கவலைப்பட வேண்டும்: நீங்கள் படிக்க முடியாத முகவரியைச் சரிபார்க்கவும் முடியாது. ஒரு பெறுநர் சேமிக்கப்பட்டதும்,
Send படிவம் அவர்களைப் பெயரால் வழங்குகிறது, நீங்கள் அதை மீண்டும் ஒட்டும்போது முகவரியை லேபிளிடுகிறது, எனவே
மாற்றப்பட்ட அல்லது துண்டிக்கப்பட்ட முகவரி கலந்துவிடாமல் தனித்துத் தெரியும்.

  • Add-ஐப் பயன்படுத்தி இங்கே ஒரு உள்ளீட்டைச் சேர்க்கவும், அல்லது Send படிவத்திலிருந்து நேரடியாக ＋ Save to contacts-ஐப் பயன்படுத்தவும்.
  • ✎ ஒரு உள்ளீட்டின் பெயரை மாற்றுகிறது, 🗑 அதை நீக்குகிறது. ஒரு தொடர்பை நீக்குவது on-chain-இல் எதையும் பாதிக்காது.
  • ⤓ பட்டியலை CSV ஆக ஏற்றுமதி செய்கிறது, எனவே அதை உங்கள் மற்ற பதிவுகளுடன் வைக்கலாம் அல்லது வேறொரு உலாவிக்கு நகர்த்தலாம்.

தொடர்புகள் உங்கள் மற்ற வாலட் தரவுடன் சேர்ந்து, இந்த உலாவியில் மட்டுமே வாழ்கின்றன. அவை பதிவேற்றப்படுவதில்லை,
மேலும் நீங்கள் வாலட்டை அழித்தால் அவை மற்ற அனைத்துடனும் சேர்ந்து அழிக்கப்படும்.

வாட்ச்-ஒன்லி கணக்குகள்

வாட்ச்-ஒன்லி கணக்கு, நீங்கள் சாவிகள் வைத்திருக்காத ஒரு முகவரியைக் கண்காணிக்கிறது — கோல்டு ஸ்டோரேஜ், ஒரு
ஹார்டுவேர் வாலட், ஒரு எக்ஸ்சேஞ்ச் வைப்பு முகவரி, அல்லது நீங்கள் கவனித்துவரும் வேறொருவரின் முகவரி.

Settings → 👥 Accounts → 👁 Watch Address-இன் கீழ் ஒன்றைச் சேர்க்கவும்: முகவரியை ஒட்டவும், அதற்கு
ஒரு பெயரிடவும், அது உங்கள் கணக்குப் பட்டியலில் சேரும்.

இது என்ன செய்ய முடியும்: இருப்பைக் காட்டலாம், வரலாற்றைப் பட்டியலிடலாம், CSV ஏற்றுமதி செய்யலாம், மேலும் PIN இல்லாமல்
அதற்கு மாறலாம் — குறிவிலக்குவதற்கு எந்த கீஸ்டோரும் இல்லை, எனவே திறக்க எதுவும் இல்லை.

இது என்ன செய்ய முடியாது: எதையும் கையொப்பமிட முடியாது. Send, குறியாக்கம்/குறிவிலக்கம், ஸ்டெல்த் பரிமாற்றங்கள், கான்ட்ராக்ட்
அழைப்புகள் மற்றும் dApp கையொப்பக் கோரிக்கைகள் அனைத்தும் மறுக்கின்றன, மேலும் Send படிவம் அதை நீங்கள் நிரப்புவதற்கு
முன்பே சொல்கிறது, பின்பு அல்ல. வாட்ச்-ஒன்லி கணக்குகள் கணக்குப் பட்டியலிலும்
ஹெடரிலும் 👁 எனக் குறிக்கப்படுகின்றன, எனவே நீங்கள் எந்த வகையைப் பார்க்கிறீர்கள் என்பது எப்போதும் உங்களுக்குத் தெரியும்.

வாட்ச்-ஒன்லி கணக்கை உண்மையான கணக்காக மாற்ற, அந்த முகவரிக்கான மீட்புச் சொற்றொடரை அல்லது தனிப்பட்ட சாவியை
இறக்குமதி செய்யவும். சாவிகளைச் சேர்ப்பதே ஒரே வழி; எந்த குறுக்குவழியும் இல்லை.

குறியாக்கப்பட்ட இருப்பு (FHE)

Orion Wallet உங்கள் இருப்பின் ஒரு பகுதியை முழுமையான ஹோமோமார்பிக் குறியாக்கத்தைப் பயன்படுத்தி குறியாக்கி வைத்திருக்க முடியும்,
எனவே அந்தத் தொகை on-chain-இல் பொதுவில் தெரியாது.

இது விருப்பத்தேர்வு. இது இயக்கப்பட்டாலும் இல்லாவிட்டாலும் மற்ற அனைத்தும் வேலை செய்கிறது.

அதை இயக்குதல்

Settings → PVAC-க்குச் செல்லவும். இரண்டு குறிகாட்டிகளும் பச்சை நிறத்தில் இருக்க வேண்டும்:

  • WASM Module — கிரிப்டோகிராஃபிக் தொகுதி ஏற்றப்பட்டது
  • Bridge Initialized — அது உங்கள் வாலட் சீட்டிலிருந்து சாவி உருவாக்கப்பட்டுள்ளது

ஏதேனும் ஒன்று தயாராக இல்லாவிட்டால், குழு (panel) சரியான காரணத்தையும் தீர்வையும் விளக்குகிறது.

குறியாக்கம் மற்றும் குறிவிலக்கம்

உங்கள் பொது மற்றும் குறியாக்கப்பட்ட இருப்புகளுக்கு இடையே நிதியை நகர்த்த Encrypt-ஐப் பயன்படுத்தவும். இந்தச்
செயல்பாடுகள் கணக்கீட்டு ரீதியாக கனமானவை மற்றும் பல விநாடிகள் ஆகலாம்; ஒரு முன்னேற்ற உரையாடல்
ஒவ்வொரு கட்டத்தையும் காட்டுகிறது.

ஸ்டெல்த் பரிமாற்றங்கள்

ஸ்டெல்த் பரிமாற்றங்கள், பெறுநரின் பொது சாவியிலிருந்து பெறப்பட்ட ஒருமுறை முகவரிக்கு நிதியை அனுப்புகின்றன,
எனவே அந்தக் கட்டணத்தை அவர்களின் முக்கிய முகவரியுடன் பொதுவில் இணைக்க முடியாது.

Stealth-ஐத் திறந்து, பெறுநர் மற்றும் தொகையை உள்ளிட்டு உறுதிப்படுத்தவும். பெறுநர் தங்கள் சொந்த Stealth தாவலில்
இருந்து நிதியைக் கோருகிறார்.

dApp-உடன் இணைத்தல்

ஒரு இணையதளம் இணைப்பைக் கோரும்போது, கோரும் ஆரிஜினைக் காட்டும் ஒரு பாப்அப் தோன்றும்.

அனுமதிக்கும் முன்:

  • ஆரிஜினைக் கவனமாகச் சரிபார்க்கவும். டொமைன் நீங்கள் எண்ணிய தளம்தானே என்பதை உறுதிப்படுத்தவும்.
  • நீங்கள் எதிர்பார்க்கும் அனுமதிகளை மட்டுமே அனுமதிக்கவும்.
  • "Trust this site" என்பது read-only கோரிக்கைகளுக்கான எதிர்கால கேட்புகளைத் தவிர்க்கிறது — அதை மிகக் குறைவாகவே பயன்படுத்தவும்.
  • பாப்அப்பில் உள்ள network தேர்வியைச் சரிபார்க்கவும். அது உங்களிடம் உள்ள ஒவ்வொரு நெட்வொர்க்கையும் — நீங்களே சேர்த்தவை உட்பட — பட்டியலிடுகிறது, எனவே பாப்அப்பை விட்டு வெளியேறாமல் சரியான நெட்வொர்க்கில் இணையலாம்.

இணைப்புகளை மதிப்பாய்வு செய்யவும் ரத்து செய்யவும் எப்போது வேண்டுமானாலும் Settings → Connected Sites-இன் கீழ் முடியும்.

பூட்டுதல் மற்றும் திறத்தல்

உங்கள் PIN வாலட்டைக் குறிவிலக்குகிறது. குறிவிலக்கப்பட்ட சாவிகள் பிறகு,
திறத்தல் செஷன் நீடிக்கும் வரை கிடைக்கின்றன — அது முடியும் வரை மீண்டும் PIN கேட்கப்படமாட்டீர்கள்.

  • பக்கத்தைப் புதுப்பிப்பது உங்களைத் திறந்த நிலையில் வைத்திருக்கும். சாவிகள் நீங்கள் இருக்கும் உலாவி தாவலுக்காக மீண்டும் சீல் செய்யப்படுகின்றன, எனவே ஒரு ரீலோடு உங்களை PIN திரைக்குத் திருப்புவதற்குப் பதிலாக செஷனை மீண்டும் எடுத்துக்கொள்கிறது. அது நடக்கும்போது சிறிது நேரம் "Restoring your session…" என்பதைக் காண்பீர்கள்.
  • தாவலை மூடுவது செஷனை முடிக்கிறது. சீல் செய்யப்பட்ட நகல் அந்த ஒரு தாவலுக்கு மட்டுமே வரம்பிடப்பட்டு அதனுடன் மறைந்துவிடும், எனவே ஒரு புதிய தாவல் அல்லது சாளரம் பூட்டப்பட்ட நிலையில் தொடங்குகிறது.
  • ஹெடரில் உள்ள 🔒 உடனடியாகப் பூட்டுகிறது மற்றும் சீல் செய்யப்பட்ட நகலை அழிக்கிறது — பூட்டிய பிறகு ஒரு ரீலோடு PIN-ஐக் கேட்கும், அது சரியே.
  • செயலற்ற தன்மை வாலட்டைப் பூட்டுகிறது — இயல்பாக 30 நிமிடங்களுக்குப் பிறகு, மேலும் ஒரு திறப்பு எப்போதும், செயல்பாடு எதுவாக இருந்தாலும், 8 மணி நேரத்திற்கு மேல் கொண்டு செல்லப்படாது.

சீல் செய்யப்பட்ட செஷனின் இரண்டு பகுதிகளில் எதுவும் தனியாகப் பயனுள்ளதாக இல்லை: குறியாக்கப்பட்ட சாவிகள்
தாவலிடம் வைக்கப்பட்டுள்ளன, அவற்றைத் திறக்கும் சாவியோ — இந்தப் பக்கமும் உட்பட — எந்தப் பக்கமும் மீண்டும் படிக்க முடியாத
வடிவத்தில் உலாவியிடம் வைக்கப்பட்டுள்ளது.

பாஸ்கீ மூலம் திறத்தல்

உங்கள் சாதனத்தில் கைரேகை ரீடர், Face ID, Windows Hello அல்லது ஒரு பாதுகாப்பு விசை இருந்தால், PIN-ஐத் தட்டச்சு செய்வதற்குப்
பதிலாக அதைக் கொண்டு திறக்கலாம்.

Settings → 🔑 Security → Passkey Unlock → Enable passkey unlock-இன் கீழ் அதை இயக்கவும். உங்கள்
சாதனம் பதிவு செய்ய உங்களைக் கேட்கும் — அது இருமுறை கேட்கலாம், ஒருமுறை பாஸ்கீயை உருவாக்கவும்
ஒருமுறை அதைப் பயன்படுத்தவும். பிறகு திறத்தல் திரை PIN பெட்டிக்கு மேலே 👆 Unlock with passkey-ஐ வழங்குகிறது.

தெரிந்துகொள்ள வேண்டியவை:

  • PIN இன்னும் உள்ளது, இன்னும் முக்கியமானது. பாஸ்கீ வாலட்டைத் திறக்கிறது; அது PIN-ஐ மாற்றுவதில்லை. சாவிகளை ஏற்றுமதி செய்வது, மீட்புச் சொற்றொடரை வெளிப்படுத்துவது, PIN-ஐ மாற்றுவது மற்றும் புதிய கணக்குகளை உருவாக்குவது ஆகிய அனைத்தும் இன்னும் அதைக் கேட்கின்றன. PIN-ஐ வைத்திருங்கள் — அதை இழப்பது பாஸ்கீ வைத்திருப்பதால் சரிசெய்யப்படாது.
  • இது இந்தச் சாதனத்துடனும் இந்த உலாவியுடனும் பிணைக்கப்பட்டுள்ளது. பாஸ்கீகள் உங்கள் வாலட் தரவுடன் பயணிப்பதில்லை. வேறொரு சாதனத்தில், PIN மூலம் திறந்து, விரும்பினால் அங்கே ஒரு பாஸ்கீயைப் பதிவு செய்யுங்கள்.
  • உங்கள் கைரேகை ஒருபோதும் வாலட்டை அடைவதில்லை. சாதனம் உங்களை உள்ளூரில் சரிபார்த்து, பாஸ்கீயிலிருந்து பெறப்பட்ட ஒரு இரகசியத்தைப் பக்கத்திடம் கொடுக்கிறது; அந்த இரகசியம்தான் வாலட்டைத் திறக்கிறது.
  • கிடைக்கும் தன்மை உங்கள் சாதனம் மற்றும் உலாவியைப் பொறுத்தது. உங்களுடையது இதற்குத் தேவையானதைச் செய்ய முடியாவிட்டால், Security குழு அதைச் சொல்கிறது, விருப்பம் முடக்கப்பட்டே இருக்கும் — PIN முன்பு போலவே சரியாக வேலை செய்கிறது.
  • பாஸ்கீ திறப்பை முடக்கவும் — அதே குழுவில். அது சேமித்த நகலை உடனடியாக நீக்குகிறது; அது உங்கள் சாதனத்திலிருந்து பாஸ்கீயை நீக்காது, அதை உங்கள் OS அல்லது உலாவி அமைப்புகளில் நீக்கலாம்.

ஒரு பாஸ்கீ எப்போதாவது வாலட்டைத் திறப்பதை நிறுத்தினால் — சுழற்றப்பட்ட அல்லது மீண்டும் பதிவு செய்யப்பட்ட சான்றிதழ், அல்லது மீட்டெடுக்கப்பட்ட சாதனம் — வாலட் அதைச் சொல்கிறது, பழைய நகலை நிராகரித்து, PIN-ஐக் கேட்கிறது. எதுவும் இழக்கப்படுவதில்லை; பிறகு ஒரு புதிய பாஸ்கீயைப் பதிவு செய்யலாம்.

வாட்ச்-ஒன்லி கணக்கு செயலில் இருக்கும்போது பாஸ்கீ திறப்பைப் பதிவு செய்ய முடியாது — அதிடம் சாவிகள் இல்லை,
எனவே பாஸ்கீ சீல் செய்வதற்கு எதுவும் இல்லை. Security குழு பொத்தானுக்குப் பதிலாக அதைச் சொல்கிறது.

செஷன் காலாவதி

அதே நேர வரம்புகள்தான் dApp இணைப்புகளையும் நிர்வகிக்கின்றன, அவை தானாகக் காலாவதியாகின்றன:

  • Idle timeout: 30 நிமிட செயலற்ற தன்மை
  • Absolute timeout: இணைப்பிலிருந்து 8 மணி நேரம்

ஒரு செஷன் காலாவதியாகும்போது, வாலட் இணைப்பை மூடுகிறது, மேலும் dApp-க்கு அறிவிக்கப்படுகிறது.
பிறகு dApp மீண்டும் இணைக்க உங்களைக் கேட்க வேண்டும்.

உங்கள் செஷன் காலாவதியாகும்போது என்ன நடக்கிறது

  1. வாலட் dApp-க்கு ஒரு sessionExpired நிகழ்வை வெளியிடுகிறது.
  2. dApp காலாவதியான செஷனைக் கண்டறிந்து ஒரு "Reconnect" கேட்பைக் காட்டுகிறது.
  3. வாலட் பாப்அப்பை மீண்டும் திறக்க நீங்கள் Connect-ஐக் கிளிக் செய்கிறீர்கள்.
  4. வாலட் உங்கள் செஷனை மீட்டெடுக்கிறது, dApp தொடர்கிறது.

ஒரு dApp தானாக மீண்டும் இணையவில்லை என்றால்

  • dApp-இல் உள்ள Connect பொத்தானைக் கிளிக் செய்யவும்.
  • வாலட் பாப்அப் திறக்கிறது — இணைப்பை அனுமதிக்கவும்.
  • உங்கள் முந்தைய செஷன் தரவு பாதுகாக்கப்படுகிறது, எனவே உங்கள் வாலட்டை மீண்டும் இறக்குமதி செய்யத் தேவையில்லை.

நெட்வொர்க் அமைப்புகள்

Settings → ⚙️ General-இல் வாலட் பேசும் RPC URL, அது வெளியே இணைக்கும் எக்ஸ்புளோரர், மற்றும் ஒரு விருப்ப ப்ராக்ஸி உள்ளன. RPC URL-ஐ மாற்றி, வாலட்டை வேறு ஒரு நோட்டில் சுட்டிக்காட்ட Save URLs-ஐத் தேர்ந்தெடுக்கவும்.

உங்கள் சொந்த நெட்வொர்க்கைச் சேர்த்தல்

Devnet மற்றும் Mainnet வாலட்டுடன் வருகின்றன. மற்றொன்றைச் சேர்க்க — உங்கள் சொந்த நோட், ஒரு டெவ்நெட் ஃபோர்க், ஒரு கட்டண RPC — அதே குழுவில் Custom Networks-க்கு உருட்டிச் சென்று பின்வருவனவற்றை நிரப்பவும்:

புலம்தேவையாகுறிப்புகள்
Network nameஆம்நெட்வொர்க் தோன்றும் எல்லா இடங்களிலும், dApp-களுக்கும் உட்பட, காட்டப்படும்
RPC URLஆம்http:// அல்லது https://
Explorer URLஇல்லைஇயல்பாக RPC URL-ஆக இருக்கும்
Relayer URLஇல்லைஸ்டெல்த் பரிமாற்றங்களுக்கு மட்டுமே தேவை

Add network-ஐத் தேர்ந்தெடுத்தால் அது பட்டியலில் சேர்கிறது. அதன் பிறகு அது ஒரு சாதாரண தேர்வாகும்:

  • மேல் பட்டியில் உள்ள network pill எந்த முன்னமைவு போலவும் அதற்கு மாறுகிறது,
  • ஒரு தளம் இணையக் கேட்கும்போது connect popup அதை (custom) எனக் குறித்து பட்டியலிடுகிறது,
  • மேலும் ஒரு இணைக்கப்பட்ட dApp அதன் பெயரையும் எக்ஸ்புளோரரையும் படிக்க முடியும், எனவே அது விஷயங்களைச் சரியாக லேபிளிடுகிறது.

நெட்வொர்க்கை மாற்றுவது மூன்று எண்ட்பாயிண்டுகளையும் ஒன்றாகப் புதுப்பிக்கிறது — RPC, எக்ஸ்புளோரர் மற்றும் ரிலேயர் — எனவே வாலட் ஒரு நெட்வொர்க்கைப் படித்துக்கொண்டே இன்னொன்றுக்கு இணைப்பதில் ஒருபோதும் முடிவதில்லை.

அதற்கு அருகில் உள்ள ✕ மூலம் ஒரு நெட்வொர்க்கை அகற்றவும். நீங்கள் தற்போது இருக்கும் ஒன்றை நீக்கினால்,
வாலட் ஒரு முன்னமைவுக்குத் திரும்பும்.

ஒரு dApp என்ன பார்க்கிறது. நீங்கள் இணைக்கும் தளங்கள் ஒரு தனிப்பயன் நெட்வொர்க்கின் பெயர், ஐகான், எக்ஸ்புளோரர் URL மற்றும் நீங்கள் அதைச் சேர்த்தீர்கள் என்பதைப் படிக்க முடியும். அவை அதன் RPC அல்லது ரிலேயர் URL-ஐ முடியாது — ஒரு வீட்டு நோட்டின் முகவரி அல்லது வழங்குநர் சாவி வாலட்டிலேயே இருக்கும். பெயர் தெரியும் என்பதால், ஒரு நெட்வொர்க்கிற்கு தனிப்பட்ட விஷயத்தின் பெயரை வைப்பதைத் தவிர்க்கவும்.

HTTPS இல்லாத நோட்கள்

ஒரு https:// நோட்டுக்குச் சிறப்பு கையாளுதல் தேவையில்லை. வெற்று http://-இல் மட்டுமே அடையக்கூடிய ஒரு நோட்
வேறு விஷயம், ஏனெனில் வாலட் அதிடம் கேட்கும் அனைத்தும் — ஒவ்வொரு இருப்பு மற்றும் வரலாற்றுத் தேடலும், அது சமர்ப்பிக்கும் ஒவ்வொரு பரிவர்த்தனையும் — வெளிப்படையாகப் பயணிக்கின்றன, அங்கே நெட்வொர்க் பாதையில் உள்ள எவரும் அதைப் படிக்கலாம் மேலும் பதில்களை மாற்றலாம். எனவே வாலட் முதலில் கேட்கிறது.

  • லூப்பேக்கிற்கு (loopback) அனுமதி தேவையில்லை. localhost, 127.0.0.1, [::1] மற்றும் ஒத்தவை உங்கள் கணினியை விட்டு ஒருபோதும் வெளியேறாது, எனவே ஒரு உள்ளூர் நோட் எந்த மாற்றமும் இல்லாமல் வேலை செய்கிறது.
  • மற்ற எந்த http:// முகவரியும் வெளிப்படையாக நம்பப்பட வேண்டும். URL-ஐ ஒட்டவும், அதற்கு அருகில் ஒரு Trust http://… பொத்தானுடன் என்ன ஆபத்து உள்ளது என்பதை குழு விளக்குகிறது. நம்பிக்கை ஒவ்வொரு ஆரிஜினுக்கும் (scheme, host மற்றும் port) சேமிக்கப்படுகிறது, எனவே ஒரு நோட்டை நம்புவது இன்னொன்றை நம்புவதில்லை, அதே host-இல் வேறு port என்பது ஒரு தனி முடிவு.
  • Trusted plaintext endpoints நீங்கள் நம்பியவற்றைப் பட்டியலிடுகிறது, அதைத் திரும்பப் பெற Remove உள்ளது.

இரண்டு வரம்புகளை எங்களால் நீக்க முடியாது, மேலும் வழியில் இருப்பது எதுவோ அதை குழு குறிப்பிடுகிறது:

  • https://-இல் வழங்கப்படும் ஒரு வாலட்டால் http://-ஐ எடுக்கவே முடியாது. உலாவிகள் அதைத் தடுக்கின்றன (அது mixed content எனப்படுகிறது), மேலும் ஆரிஜினை நம்புவது அதை மாற்றாது. நோட்டை TLS-க்குப் பின்னால் வைக்கவும், ஒரு ப்ராக்ஸியைப் பயன்படுத்தவும், அல்லது வாலட்டை வெற்று-http அல்லது localhost பில்டிலிருந்து திறக்கவும்.
  • விநியோகிக்கப்பட்ட பில்ட் https:// மற்றும் லூப்பேக்கை மட்டுமே அனுமதிக்கிறது. அதன் பாதுகாப்புக் கொள்கை பில்ட் நேரத்தில் நிர்ணயிக்கப்படுகிறது, இயங்கும்போது விரிவாக்க முடியாது. வெற்று http தேவைப்படும் சுய-ஹோஸ்டர்கள் VITE_ALLOW_HTTP_ENDPOINTS=1-உடன் பில்ட் செய்யலாம்; மேலே உள்ள நம்பிக்கை பட்டியல் அதற்கு மேலும் பொருந்தும்.

எக்ஸ்புளோரர் URL இவை அனைத்திலிருந்தும் விலக்கு — அது நீங்கள் கிளிக் செய்யும் ஒரு இணைப்பு மட்டுமே,
வாலட் எடுக்கும் (fetch) ஒன்று அல்ல.

RPC ப்ராக்ஸி

RPC proxy (optional) அழைப்புகளை நீங்கள் தேர்வுசெய்யும் ஒரு URL வழியாக அனுப்புகிறது: RPC URL அதனுடன் சேர்க்கப்படுகிறது, percent-encoded வடிவில், மேலும் உலாவி எப்போதும் ப்ராக்ஸிக்கே இணைக்கிறது. TLS இல்லாத அல்லது CORS ஹெடர்கள் இல்லாத ஒரு நோட்டுக்கு இதுவே நடைமுறை தீர்வு, மேலும் உலாவி செய்யும் இணைப்பு ப்ராக்ஸியுடன் இருப்பதால் மேலே உள்ள விதிகளையும் அது பூர்த்தி செய்கிறது.

ப்ராக்ஸி வாலட் செய்யும் ஒவ்வொரு கோரிக்கையையும் பார்க்கிறது, எனவே உங்கள் சொந்த ப்ராக்ஸியை இயக்கவும். அதனால் எதையும் கையொப்பமிடவோ உங்கள் சாவிகளை அடையவோ முடியாது, ஆனால் அது பார்க்க முடியும், பொய் சொல்லவும் முடியும்.

ஏதோ சரியில்லாதபோது
