Orion Wallet — 用户指南

Orion Wallet 完全运行在您的浏览器中。您的密钥在本地生成，使用您的 PIN 码
加密，并且只存储在您自己的设备上。任何数据都不会发送到服务器。

GitHub: github.com/maragung/OrionWallet — 源代码、问题反馈与版本发布。

快速开始

系统要求

  • 较新版本的 Chrome、Edge、Firefox 或 Safari
  • 已启用 JavaScript
  • 如果您打算使用加密余额功能，约需 4 GB 内存

运行方式

可使用已托管的部署，或在本地运行：

npm install --legacy-peer-deps
npm run dev

然后打开 <http://localhost:5173>。

创建钱包

  1. 选择 Create New Wallet，为账户命名，并设置一个 PIN 码。该 PIN 码会在本设备上加密钱包。
  2. 抄写下您的恢复助记词。系统会显示 12 个单词。请按照给出的确切顺序将它们抄写到纸上。
  3. 选择 I've Written It Down。随后钱包会要求您重新输入随机抽取的其中 3 个单词，以证明助记词确实离开过屏幕。如果需要再看一次，Show Phrase Again
    可将其重新显示；答错也只是让您重试而已。
  4. 单词核对无误后，钱包便会打开。
创建钱包本身并不会打开它——通过单词核对才会。在此之前您
仍可随时离开，不会丢失任何东西，因为此时还没有真正依赖该助记词。
您的恢复助记词是恢复钱包的唯一方式。任何持有它的人
都能掌控您的资金。请离线保存。切勿拍照、切勿输入到任何网站，
也不要粘贴到聊天或邮件中。

PIN 码与恢复助记词的对比

恢复助记词PIN 码
用途可在任何地方恢复您的钱包仅在本设备上解锁钱包
若丢失资金无法找回可通过恢复助记词重新恢复
存储位置由您离线保管从不存储——只有您自己知道

导入现有钱包

选择 Import，然后从以下方式中选择一种：

  • 恢复助记词 — 输入您的 12/24 个单词
  • 私钥 — 粘贴一个 base64 编码的私钥
  • 钱包文件 — 上传一个加密的 .oct 文件并输入其 PIN 码

日常使用

查看余额

Balance 标签页会显示您的公开余额；如果已启用 PVAC，还会显示您的加密余额。

收款

打开 Receive 即可显示您的地址和一个二维码。您的地址是公开的，
可以安全地分享。

您也可以请求指定金额。此时二维码会在地址之外一并携带该金额
（形如 octra:<address>?amount=<OCT>），因此扫描它的钱包会同时预填两者。
若未请求金额，二维码则只是一个纯地址，任何扫描器都能读取。

发送

  1. 打开 Send。
  2. 以任意适合您的方式指定收款人：
    • 粘贴地址（以 oct 开头）。
    • 从 📇 Contacts… 中选取一个已保存的名称。
    • 选择 📷 Scan，用您的摄像头读取二维码。浏览器首次会请求摄像头权限；图像会在页面内处理，绝不会上传。若扫描的二维码带有金额，也会一并填入金额。
  3. 输入金额。
  4. 核对手续费与 nonce，然后用您的 PIN 码确认。

当地址与某个已保存的联系人匹配时，表单会在其旁边显示名称——比起一串 base58，
您认得的名称是好得多的核对方式。对于新地址，＋ Save to
contacts 会把它保存在您所选的标签下，这样下次付款只需选择，而无需粘贴。

确认前，请务必核对收款地址的开头和结尾字符。
交易一经发出便无法撤销。

历史记录

History 会列出近期的交易。当网络无法访问时，会显示已缓存的条目
并标记为 ⚠ Cached。

⤓ 可将表格导出为 CSV 文件（时间、哈希、类型、发送方、接收方、方向、金额、手续费、
状态），供电子表格或您自己的记录使用。它导出的是当前已加载的行——
所见即所得——因此若想导出更长的范围，请先使用 Load more。该文件
会由您的浏览器写入下载文件夹；不会向任何地方发送任何内容。

联系人（地址簿）

Settings → 📇 Contacts 会以您所选的名称保存一份地址列表。每个条目都有
一个地址、一个名称，以及一条可选的备注——很适合记录"需要 memo"，或某个存款地址
属于哪家交易所。

为何值得这样做：读不懂的地址就是无法核对的地址。一旦保存了某个收款人，
发送表单便会以名称提供该收款人，并在您粘贴回其地址时为其标注名称，这样
被调换或被截断的地址便会显眼地暴露出来，而不会混杂其中。

  • 在此处 Add 添加一个条目，或直接在发送表单中使用 ＋ Save to contacts。
  • ✎ 可重命名条目，🗑 可将其删除。删除联系人不会对链上产生任何影响。
  • ⤓ 可将列表导出为 CSV，以便与您的其他记录一起保存，或迁移到另一个浏览器。

联系人仅保存在本浏览器中，与您其余的钱包数据存放在一起。它们不会被上传，
并且在您清除钱包时会与其他一切一并被抹除。

仅观察账户

仅观察账户用于追踪一个您并不持有其密钥的地址——冷存储、
硬件钱包、交易所存款地址，或您留意的他人地址。

在 Settings → 👥 Accounts → 👁 Watch Address 下添加：粘贴地址、为其
命名，它便会加入您的账户列表。

它能做什么：显示余额、列出历史记录、导出 CSV，并且无需 PIN 码即可切换到它
——没有需要解密的密钥库，因此也没有什么需要解锁。

它不能做什么：无法进行任何签名。发送、加密/解密、隐身转账、合约
调用以及 dApp 签名请求都会被拒绝，而且发送表单会在您填写之前而非之后就说明这一点。
仅观察账户在账户列表和顶栏中都标记为 👁，因此您始终清楚自己正在查看的是哪一种。

要把仅观察账户变为真正的账户，请为该地址导入恢复助记词或私钥。
添加密钥是唯一的方式，没有捷径。

加密余额（FHE）

Orion Wallet 可以使用全同态加密将您的部分余额以加密形式持有，
因此该金额不会在链上公开可见。

这是可选功能。无论是否启用它，其余一切都能正常工作。

启用方法

前往 Settings → PVAC。以下两个指示器必须都为绿色：

  • WASM Module — 加密模块已加载
  • Bridge Initialized — 它已由您的钱包种子完成密钥初始化

如果其中任一项尚未就绪，面板会说明确切的原因和解决办法。

加密与解密

使用 Encrypt 在您的公开余额与加密余额之间转移资金。这些
操作计算量很大，可能需要几秒钟；进度对话框会
逐一显示每个阶段。

隐身转账

隐身转账会将资金发送到一个由收款人公钥派生出的一次性地址，
因此这笔付款不会在公开层面与其主地址关联起来。

打开 Stealth，输入收款人和金额，然后确认。收款人可从自己的 Stealth
标签页中领取这笔资金。

连接到 dApp

当某个网站请求连接时，会弹出一个窗口，显示发起请求的来源（origin）。

批准之前：

  • 仔细核对来源。确认该域名正是您想要访问的站点。
  • 只批准您预期的权限。
  • "Trust this site" 会在今后跳过对只读请求的提示——请谨慎使用。
  • 查看弹窗中的网络选择器。它会列出您拥有的每一个网络，包括您自己添加的那些，因此您无需离开弹窗即可在正确的网络上连接。

您可以随时在 Settings → Connected Sites 下查看并撤销连接。

锁定与解锁

您的 PIN 码用于解密钱包。解密后的密钥会在解锁会话持续期间一直保持可用
——在会话结束之前，不会再次要求您输入 PIN 码。

  • 刷新页面不会让您退出解锁状态。密钥会为您所在的浏览器标签页重新封装，因此重新加载会重新接上该会话，而不会把您退回到 PIN 码输入界面。发生这一切时，您会短暂看到"Restoring your session…"。
  • 关闭标签页会结束会话。封装后的副本仅限于该标签页，会随它一起消失，因此新的标签页或窗口在启动时都处于锁定状态。
  • 顶栏中的 🔒 会立即锁定并销毁封装副本——锁定后重新加载会要求输入 PIN 码，这正是应有的行为。
  • 不活动会锁定钱包，默认在 30 分钟后触发；而且无论是否有活动，单次解锁的有效期都绝不会超过 8 小时。

封装后的会话，两半单独拿出来都毫无用处：加密后的密钥由标签页持有，
而打开它们的密钥则由浏览器以一种任何页面——
包括本页面——都无法读回的形式保管。

在 Settings → Security → Session & Auto-Lock 下：

设置项默认值作用
刷新页面后保持解锁开启关闭后，每次重新加载都需要输入 PIN 码
不活动后自动锁定30 分钟5 / 15 / 30 / 60 分钟，或永不（直到标签页关闭）

两者会同时生效，也包括您当前已打开的会话。在共用或
不受信任的电脑上，请关闭第一项，并在离开时锁定钱包。

使用通行密钥解锁

如果您的设备配有指纹识别器、Face ID、Windows Hello 或安全密钥，您就可以
用它来解锁，而无需输入 PIN 码。

在 Settings → 🔑 Security → Passkey Unlock → Enable passkey unlock 下开启。您的
设备会提示您进行注册——它可能会提示两次，一次用于创建通行密钥，
一次用于使用它。之后解锁界面会在 PIN 码输入框上方提供 👆 Unlock with passkey。

值得了解的几点：

  • PIN 码依然存在，也依然重要。通行密钥用于打开钱包，它并不取代 PIN 码。导出密钥、显示恢复助记词、更改 PIN 码以及派生新账户，都仍然需要它。请保留好 PIN 码——丢失它并不能靠拥有通行密钥来弥补。
  • 它与本设备和本浏览器绑定。通行密钥不会随您的钱包数据一起迁移。在另一台设备上，请用 PIN 码解锁；如有需要，可在那里再注册一个通行密钥。
  • 您的指纹绝不会传到钱包。设备会在本地验证您的身份，并把一个由通行密钥派生出的秘密交给页面；正是这个秘密打开了钱包。
  • 可用性取决于您的设备和浏览器。如果您的设备无法满足这项功能的需要，安全面板会予以说明，并让该选项保持关闭——PIN 码会像以前一样继续正常工作。
  • 关闭通行密钥解锁也在同一面板中进行。这会立即删除所存储的副本；但不会从您的设备上删除该通行密钥，您可以在操作系统或浏览器设置中将其移除。

如果某个通行密钥有朝一日无法再打开钱包——凭据被轮换或重新注册，或设备被恢复——
钱包会予以说明，丢弃已失效的副本，并要求输入 PIN 码。不会丢失任何东西；
之后您可以重新注册一个新的通行密钥。

当仅观察账户处于活动状态时，无法注册通行密钥解锁——它不持有任何密钥，
因此没有东西可供通行密钥封装。安全面板会在按钮的位置说明这一点。

会话过期

同样的时限也适用于 dApp 连接，它们会自动过期：

  • 空闲超时：不活动 30 分钟
  • 绝对超时：自连接起 8 小时

当会话过期时，钱包会关闭该连接，并通知 dApp。
随后 dApp 应提示您重新连接。

会话过期时会发生什么

  1. 钱包向 dApp 发出一个 sessionExpired 事件。
  2. dApp 检测到会话已过期，并显示一个"Reconnect"提示。
  3. 您点击 Connect 以再次打开钱包弹窗。
  4. 钱包恢复您的会话，dApp 随之继续运行。

如果 dApp 没有自动重新连接

  • 点击 dApp 中的 Connect 按钮。
  • 钱包弹窗打开——批准该连接。
  • 您之前的会话数据会被保留，因此您无需重新导入钱包。

网络设置

Settings → ⚙️ General 中保存着钱包所连接的 RPC URL、它向外链接的
区块浏览器，以及一个可选的代理。更改 RPC URL 并选择 Save URLs，即可将钱包
指向另一个节点。

添加您自己的网络

钱包内置了 Devnet 和 Mainnet。要添加其他网络——您自己的节点、一个 devnet 分叉、
一个付费 RPC——请在同一面板中滚动到 Custom Networks 并填写：

字段是否必填说明
网络名称是会显示在该网络出现的所有位置，包括面向 dApp
RPC URL是http:// 或 https://
Explorer URL否默认与 RPC URL 相同
Relayer URL否仅隐身转账时需要

选择 Add network，它便会加入列表。此后它就是一个普通的选项：

  • 顶栏中的网络标签（network pill）会像切换任何预设一样切换到它，
  • 当某个站点请求连接时，连接弹窗会将其列出，并标记为 (custom)，
  • 已连接的 dApp 可以读取它的名称和区块浏览器，从而正确地进行标注。

切换网络会同时更新全部三个端点——RPC、区块浏览器和 relayer——因此钱包
绝不会出现读取一个网络却链接到另一个网络的情况。

用旁边的 ✕ 删除某个网络。如果您删除的是当前正在使用的网络，
钱包会回退到某个预设。

dApp 能看到什么。您连接的站点可以读取自定义网络的名称、图标、区块浏览器
URL，以及您添加了它这一事实。它们无法读取其 RPC 或 relayer URL——家用
节点的地址或提供商密钥都留在钱包中。由于名称是可见的，请避免
用带有个人信息的名称来命名网络。

没有 HTTPS 的节点

https:// 节点无需特殊处理。而只能通过纯 http:// 访问的节点则是
另一回事，因为钱包向它发出的一切——每一次余额和历史记录查询、
它提交的每一笔交易——都以明文传输，网络路径上的任何人都能读取，
并篡改返回的结果。因此钱包会先征询您的许可。

  • 环回地址无需授权。localhost、127.0.0.1、[::1] 等永远不会离开您的机器，因此本地节点开箱即用。
  • 任何其他 http:// 地址都必须显式信任。粘贴该 URL，面板会通过旁边的一个 Trust http://… 按钮说明其中的利害关系。信任是按来源（scheme、主机和端口）存储的，因此信任一个节点并不会信任另一个，而同一主机上的不同端口是一个单独的决定。
  • Trusted plaintext endpoints 会列出您已信任的项，并可通过 Remove 将其收回。

有两项限制不是我们所能解除的，面板会指出当前挡在路上的是哪一项：

  • 通过 https:// 提供的钱包根本无法获取 http://。浏览器会拦截这种情况（这被称为混合内容），信任该来源也无法改变它。请把节点置于 TLS 之后、使用代理，或从纯 http 或 localhost 构建版本打开钱包。
  • 发行的构建版本只允许 https:// 和环回地址。它的安全策略在构建时就已固定，无法在运行时放宽。需要纯 http 的自托管用户可以使用 VITE_ALLOW_HTTP_ENDPOINTS=1 进行构建；上面的信任列表仍会在此之上生效。

区块浏览器 URL 不受上述所有这些限制——它始终只是您点击的一个链接，
而不是钱包会去获取的东西。

RPC 代理

RPC proxy (optional) 会将调用通过您选择的一个 URL 进行路由：RPC URL 会经
百分号编码后追加到它后面，浏览器始终只连接到该代理。对于没有 TLS 或没有 CORS
头的节点，这是切实可行的解决办法，而且它满足上述规则，
因为浏览器所建立的连接是指向代理的。

代理能看到钱包发出的每一个请求，因此请运行您自己的代理。它无法签署任何东西，
也无法接触您的密钥，但它可以监视，也可以撒谎。

出现异常时

如果 RPC 端点无法按当前配置使用，顶栏会出现 ⚠️ Insecure RPC；
选中它即可直接跳转到相应设置。网络错误也会附带原因，因此一句干巴巴的
"Failed to fetch" 就能告诉您该修什么。

备份与恢复

导出

Settings → Backup → Export 会下载一个加密的 .oct 文件。它受
您的 PIN 码保护，但请将其视为敏感文件。

恢复

使用 Import → Wallet file，并提供导出该文件时所用的 PIN 码。

多个账户

Settings → Accounts 会从同一个恢复助记词派生出更多账户。一个
助记词即可恢复它们全部。

有两样东西是助记词无法恢复的，因为它们从来就不是由它派生出来的：

  • 仅观察账户 — 它们只是您让钱包追踪的一些地址。如果您希望在重装后仍能找回它们，请另行单独记录。
  • 联系人 — 如果它们对您很重要，请在 Settings → Contacts 下用 ⤓ 导出。

两者都不持有资金，因此丢失它们损失的是便利，而不是钱。

故障排查

页面空白或卡在加载中

重新加载。如果问题依旧，应会出现一张带 Retry 按钮的错误卡片。请报告
其中显示的信息。

加密余额不可用

Settings → PVAC 会显示以下之一：

信息含义解决办法
The WASM module has not been compiledpvac.js 未被提供运行 npm run build:wasm
Content-Security-Policy is blocking WebAssemblyCSP 缺少 'wasm-unsafe-eval'将其添加到 index.html 中的 script-src

"Failed to load history" / 网络错误

通常是 RPC 节点无法访问或在拦截 CORS。请在 Settings 下核对 RPC URL，
并参阅 CORS 说明。如果错误指明了原因——
明文、混合内容或构建限制——请参阅
网络设置；RPC 代理可解决 CORS 这种情况。

顶栏显示"⚠️ Insecure RPC"

所配置的 RPC 端点是纯 http://，按当前状态不可用。选中该
徽标即可打开相应设置，其中会详细说明确切原因和解决办法。请参阅
网络设置。

当我选择 📷 Scan 时摄像头打不开

  • 当浏览器询问时，请授予摄像头权限；如果您之前忽略了它，请在站点权限中重新允许，然后再试一次。
  • 摄像头访问需要安全页面。它在 https:// 和 localhost 上可用，但在另一主机上的纯 http:// 页面上不可用。
  • 如果有其他应用占用了摄像头，请先将其关闭。您也随时可以改为粘贴地址。

未提供"Unlock with passkey"

要么本浏览器中没有注册任何通行密钥，要么设备无法满足通行密钥解锁
所需的条件。Settings → 🔑 Security → Passkey Unlock 会说明是哪一种。通行密钥是按设备
和按浏览器区分的，因此在别处注册的通行密钥不会出现在这里。PIN 码始终有效。

我忘记了 PIN 码

使用您的恢复助记词重新安装钱包，并设置一个新的 PIN 码。没有该助记词，
资金就无法被找回——任何人都不能。

"Could not read your saved wallets" / "Could not read your accounts"

钱包无法打开它的本地数据库。没有任何东西被删除——这几乎
总是因为另一个 Orion 标签页，或一个残留的 Connect 弹窗仍占用着该数据库。
在更新之后，只要还有较旧的标签页连接着数据库，浏览器就不会升级它。

关闭其他的 Orion 标签页和弹窗，然后选择 ↻ Try again。如果该信息仍然存在，
请关闭每一个 Orion 标签页，并在单个标签页中重新打开钱包。

解锁界面特意区分了这两种状态：No stored wallet found 表示数据库
确实是空的，而 Could not read your saved wallets 表示您的账户
确实存在，只是暂时无法访问。当您看到第二条信息时，请勿创建新钱包。

更新后我的钱包不见了

首次启动时，数据会自动从较旧的构建版本迁移过来。如果您的账户
不见了，请勿创建新钱包——那可能会覆盖旧数据。请报告该
问题，同时先用您的恢复助记词进行恢复。

dApp 提示"Session expired"

这表示钱包会话已超时（空闲 30 分钟 / 绝对 8 小时）。请在 dApp 中
点击 Connect 重新连接。您的钱包数据会被保留——您只需
重新批准该连接。

保护您的资金安全

应当

  • 将恢复助记词离线保存在纸上，最好存放在不止一个地点
  • 发送前核对收款地址
  • 核对 dApp 连接提示中显示的来源
  • 向新地址发送时，先从一笔小额测试交易开始
  • 将收款人保存为联系人，并核对名称——您认得的名称胜过去读 base58
  • 使用仅观察账户来留意冷存储，而不是解锁真正的账户

切勿

  • 在任何网站上输入您的恢复助记词。Orion Wallet 在设置之后绝不会索要它
  • 将助记词保存在截图、密码管理器备注、云盘或聊天中
  • 分享您的私钥或 .oct 文件
  • 在共用或不受信任的电脑上使用持有真实资金的钱包
