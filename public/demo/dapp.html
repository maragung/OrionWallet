Orion Wallet — dApp Integration Demo

A live, self-contained reference for integrating Orion Wallet via the SDK — connection, session health checks, refresh-on-expiry, and simulated buy/sell/swap.

Connection

Status: disconnected
Integration pattern: dApps call provider.connect() to open the wallet popup. After connect, use await provider.isAlive() (or provider.ping() for full detail) before every signing operation. If the session has expired, call provider.connect() again to reopen the popup and re-establish the channel — and note that every request already reconnects transparently when the transport is gone.

Session Expiry Handling

Orion sessions expire after 30 min idle or 8 hours absolute. When expired, the wallet emits a sessionExpired event and the dApp should prompt the user to reconnect.

Integration Guide

1. Import the SDK 
// No build step needed — served straight from the wallet origin
// (the npm package is not published yet):
const { WalletProvider } = await import(
  'https://orionwallet.vercel.app/sdk/orion-wallet-sdk.mjs'
);
2. Create the provider 
const provider = new WalletProvider({
  walletUrl: 'https://orionwallet.vercel.app/connect',
  capabilities: [
    'signMessage',
    'signTypedData',
    'approveContract',
    'signContract',
    'multiAccount',
    'events',
    'sessionRestore',
  ],
});
3. Connect 
const result = await provider.connect();
console.log(result.address); // Connected address
4. Check session before signing 
// isAlive() pings the wallet and never throws;
// every request() also auto-reconnects on its own.
if (!(await provider.isAlive())) {
  await provider.connect(); // reopens popup, re-establishes the session
}
const sig = await provider.signContract({...});
5. Listen for session expiry 
provider.on('sessionExpired', () => {
  // Prompt user to reconnect
  setConnected(false);
});
